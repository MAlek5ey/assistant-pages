Политика конфиденциальности

Приложение «assistant». Обновлено 4 сентября 2026 года.

Кто пользуется приложением

У приложения один пользователь — его автор. Регистрации, входа для посторонних и передачи доступа третьим лицам не предусмотрено.

Какие данные используются

С разрешения владельца приложение обращается к его собственному аккаунту Google:

  • https://www.googleapis.com/auth/gmail.modify — чтение писем, отметки о прочтении, ярлыки, архивирование, черновики
  • https://www.googleapis.com/auth/calendar.events — чтение и создание событий календаря
  • https://www.googleapis.com/auth/tasks — чтение и изменение списка задач

Как данные обрабатываются и хранятся

  • Обработка идёт локально, на личном компьютере владельца. Сервера у приложения нет.
  • Токены доступа хранятся в файлах в каталоге %USERPROFILE%\.assistant\ на этом же компьютере.
  • Тела писем и содержимое документов на диск не сохраняются. В рабочие заметки попадают только отправитель, тема, идентификатор письма и краткая суть в одну-две строки.
  • Данные не передаются третьим лицам, не продаются, не используются для рекламы и не применяются для обучения моделей.
  • Аналитики, трекеров и сбора статистики в приложении нет.

Сколько данные хранятся

Токены хранятся, пока владелец не отзовёт доступ или не удалит файлы. Заметки о выполненных действиях владелец удаляет самостоятельно в любой момент — они лежат обычными файлами на его диске.

Как отозвать доступ

В любой момент на странице myaccount.google.com/permissions выбрать приложение и отключить доступ. Дополнительно можно удалить файлы токенов из каталога %USERPROFILE%\.assistant\.

Ограниченное использование данных Google

Использование приложением сведений, полученных через Google API, отвечает Политике Google API Services User Data Policy, включая требования Limited Use.

Контакт

Приложение частное и рассчитано на одного пользователя — своего автора. Адрес для связи указан в настройках приложения в Google Cloud и показывается на экране запроса доступа при подключении аккаунта.

Privacy Policy

Application “assistant”. Last updated 4 September 2026.

Who uses this application

The application has a single user — its author. There is no sign-up, no access for other people, and no sharing of access with third parties.

What data is accessed

With the owner's consent, the application accesses the owner's own Google account:

  • gmail.modify — reading messages, marking as read, labels, archiving, drafts
  • calendar.events — reading and creating events in the personal calendar
  • tasks — reading and modifying the task list

How data is processed and stored

  • All processing happens locally on the owner's personal computer. The application has no server.
  • Access tokens are stored in files under %USERPROFILE%\.assistant\ on that same computer.
  • Message bodies and document contents are not saved to disk. Working notes keep only the sender, subject, message id and a one- or two-line summary.
  • Data is never shared with third parties, sold, used for advertising, or used to train models.
  • The application contains no analytics or tracking.

Data retention

Tokens are kept until the owner revokes access or deletes the files. Working notes are plain files on the owner's disk and can be deleted at any time.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions, and the token files under %USERPROFILE%\.assistant\ can be deleted.

Limited Use

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

This is a private, single-user application. The contact address is configured in the application's Google Cloud settings and is shown on the consent screen when the account is connected.
